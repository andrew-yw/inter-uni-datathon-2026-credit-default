# Final submission rules and checklist

Sources: organizer-provided `Expected Submission Materials.pdf` and the official announcement supplied to the team on 6 September 2026. These are administrative requirements, not model-training data.

## Deadline and one-submission rule

- Submit by midnight at the end of Sunday, 6 September 2026.
- Each team may make only one final submission.
- Only one team member needs to submit.
- Use a public GitHub repository containing the final code and the exact final submission generated by that code.

## Required materials

- Final notebook or methodology report covering the approach, cleaning, preprocessing, feature engineering, validation, models tested, final selection, ensembling/post-processing, key results, observations, and limitations.
- Complete source code for data loading, preprocessing, feature generation, training, validation, test inference, post-processing, and submission generation.
- The exact prediction file corresponding to the leaderboard submission under finalist review; do not recreate or modify it unless clearly stated.
- Processed/cleaned data if required, or clear code identifying the relevant generation step.
- A README with required files, execution order, dependencies, important seeds/settings, and the command that generates the final prediction file.
- Final model or ensemble identification, hyperparameters/weights, and clear identification of any pretrained or external package.

## Required disclosure

Disclose external datasets; external code, notebooks, repositories, or public solutions; pretrained models; AI tools or coding agents; manual modification or prediction post-processing; and any additional information beyond competition-provided files. AI use is not automatically misconduct; provenance and reproducibility are the purpose of disclosure.

## Review standard

The submitted materials must plausibly reconstruct the full path from competition data through preprocessing, modelling, inference, post-processing, and final submission. Missing documentation alone is not automatically disqualifying, but material that cannot explain or reproduce the leaderboard result may be held for technical review or deemed ineligible.

## Final pre-submission checklist

- [ ] `python scripts/train_archive_ensemble.py` completes from the pinned environment.
- [ ] `submission.csv` hash matches `ensemble_config.json` and `artifacts/archive_ensemble_v1/run_manifest.json`.
- [ ] The exact same `submission.csv` has been uploaded to the competition.
- [ ] The leaderboard score has been recorded in `METHOD.md` without modifying the CSV.
- [ ] Repository visibility is public.
- [ ] No external source labels, UCI reconstruction data, secrets, or prohibited raw data are committed.
- [ ] One designated team member submits the repository once before the deadline.
